WHY THIS EXISTS

Built by people who use OsiriX every day.

Real radiology use

Every plugin comes from a real frustration or a wishlist item in the reading room. We build around what radiologists actually need.

Native to macOS

Built with OsiriX's own plugin API, so it behaves like part of the app, not a bolted-on extension.

Self-contained

Just one plugin, no external tools or dependencies to install. You configure the basics, but everything lives inside the plugin itself.
